# iLab@home — print files

Logo artwork for the print shop. Every file uses the approved logo exactly as it appears on the site.

| File | Use |
|---|---|
| `logo_mark_blue` / `logo_mark_white` | Logo only. Use for the cap (embroidery) and small items |
| `logo_lockup_blue` / `logo_lockup_white` | Logo with the name side by side. Use for the mug and business card |
| `logo_stack_blue` / `logo_stack_white` | Logo above the name. Use for the t-shirt, tote bag, bottle and notebook |

- **PDF** is the vector version. It scales to any size, so send it to the printer first.
- **PNG** has a transparent background and is about 2500–3900 px wide, which is 300 dpi at roughly 21–33 cm.
- Use the blue version on light products and the white version on navy/dark products.
