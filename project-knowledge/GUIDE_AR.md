# دليل مشروع آي لاب@هوم — كيف مبني ووين كل شي

دليل لبلعرب عشان يعرف كل جزء في المشروع ويشرحه بنفسه.

## ١. ويش مستخدم في المشروع (التقنيات)

| الجزء | التقنية | ليش |
|---|---|---|
| الواجهة | **HTML + CSS + JavaScript عادي** (بدون React أو أي إطار) | خفيف وسريع، ويشتغل على أي تلفون، وبدون خطوة بناء (build) |
| تطبيق على الجوال | **PWA**: ملف `sw.js` (Service Worker) و`manifest.webmanifest` | يتثبت على الشاشة الرئيسية مثل تطبيق، ويشتغل حتى لو النت ضعيف |

| الحماية | RLS (منع الوصول المباشر للجداول) + دوال `SECURITY DEFINER` + كلمات مرور مشفرة bcrypt + CSP في `vercel.json` | ما أحد يقدر يقرأ بيانات غيره |

| دوال السيرفر | `api/chat.js` (المساعد) · `api/mail.js` (الإيميلات) · `api/push.js` (التنبيهات) · `api/google.js` (الدخول بقوقل) | أي شي يحتاج مفتاح سري يكون في السيرفر، مو في المتصفح |
| الحركات | **GSAP** (`vendor/gsap`) + CSS animations + Web Animations | حركات ناعمة؛ وتتوقف لحالها في الأجهزة الضعيفة أو إذا المستخدم طالب حركة أقل |
| البنر الثلاثي الأبعاد | **Three.js** (`js/hero3d.js`) | مشاهد ثري دي في الصفحة الرئيسية |
| الخرائط | **Leaflet** + OpenStreetMap | خريطة موقع الزيارة |
| الخطوط | IBM Plex Sans Arabic (عربي) · Inter (إنجليزي) | من Google Fonts |
| الفحص | **Playwright** (`tools/qa`) | يفتح الموقع على ٢٠ جهاز ويفحص كل زر وكل شاشة |

## ٣. الألوان — وين تغيّرها بسطر واحد

الألوان كلها «متغيرات» في `css/app.css`:

**السطر 1 إلى 8** (الأساس):
```css
:root{
  --blue:#1257d6; --blue-2:#2f7bff; --navy:#0b2350; --ink:#0f1b33; --muted:#5b6b88; --line:#e3e9f4;
  --bg:#f4f7fc; --card:#fff; --sky:#eaf2ff; --teal:#0fae9b; --teal-bg:#e3f7f4; --amber:#f2a516; --amber-bg:#fff4dc;
  --red:#e2474f; --red-bg:#fdecec; --purple:#7a5af8;
  --r:18px; ...
  --font:'Inter',system-ui,...;
}
```

**السطر 389** يغطي على بعضها (هذا اللي شغال فعلياً للأزرق والكحلي):
```css
:root{--blue:#2563eb;--blue-2:#3b82f6;--navy:#0d1628;--navy-2:#14254a;--sky:#eaf1ff; ...}
```

| المتغير | وين يبان |
|---|---|
| `--blue` | الأزرار، الروابط، الأيقونات الأساسية |
| `--navy` | العناوين، الشريط الكحلي، أسفل الموقع |
| `--ink` | لون الكلام |
| `--muted` | الكلام الرمادي الخفيف |
| `--bg` | خلفية الصفحة |
| `--card` | خلفية البطاقات |
| `--teal` | الأخضر: «تم»، «في السلة» |
| `--amber` / `--red` | التنبيهات والنتائج غير الطبيعية |
| `--r` | دوران زوايا البطاقات |

**مثال:** تبي الأزرق أغمق؟ غيّر `--blue:#2563eb` في السطر 389 إلى `--blue:#1d4ed8`، والموقع كله يتغير مرة وحدة.

**الخط:** السطر 6 (`--font`) للإنجليزي، والسطر 9 للعربي: `html[lang=ar]{--font:'IBM Plex Sans Arabic',...}`.

## ٤. النصوص — وين تغيّر أي كلام

كل الكلام في `js/i18n.js`: الإنجليزي من السطر 2، والعربي من السطر 117. كل جملة لها مفتاح، مثلاً:
```js
hero_t1:'Lab tests at home,',          // السطر 6
hero_t1:'فحوصاتك المخبرية في البيت،',   // السطر 120
```
غيّر الكلام بين علامتي `'...'` بس، ولا تلمس المفتاح.

## ٥. كيف يشتغل البرنامج (عشان تشرحه)

1. `index.html` يحمّل الملفات بالترتيب: `store.js` ← `i18n.js` ← `art.js` ← `api.js` ← ... ← `app.js`.
2. `app.js` يقرأ الرابط بعد `#` (مثلاً `#/app/tests`) في دالة `renderNow` (السطر 1787 تقريباً)، ويرسم الشاشة المناسبة. هذا اسمه **hash router**: تطبيق صفحة وحدة (SPA).
3. كل شاشة دالة: `viewTests`، `viewBook`، `viewOrders`، `viewAdminUsers`... وكلها تستخدم `shell()` (السطر 359) اللي ترسم الإطار: الشريط، والقائمة الجانبية، والشريط السفلي.
4. القائمة حسب نوع الحساب في `navFor(role)` (السطر 346): مريض، ممرض، مندوب، مختبر، شركة، طبيب، مدير.
5. البيانات: `api.js` يرسل طلب لدالة في Supabase (مثل `orders_list`). الدالة في قاعدة البيانات تتأكد من هوية الشخص وصلاحيته، وترجع بياناته هو بس.
6. السلة محفوظة في الجوال نفسه (`localStorage`)، والحجز يروح لقاعدة البيانات.
7. `sw.js` يحفظ الملفات في الجوال. كل ما تنشر نسخة جديدة لازم ترفع رقم النسخة عشان الجوالات تاخذ الجديد.

## ٦. النشر (خطوات كل تحديث)

1. ارفع رقم النسخة: `?v=N` في `index.html` و`sw.js`، و`lah-vN` في `sw.js`، و`APP_V` في `js/app.js`.
2. شغّل الفاحص: `tools/qa/run-all.sh`
3. اعمل commit و push لفرع `lab-at-home`.
4. انشر من Vercel، وجرّب الموقع على جوال وكمبيوتر.

## ٧. أسئلة متوقعة، وأجوبة صادقة

- **ويش استخدمت؟** واجهة HTML/CSS/JavaScript بدون إطار، وقاعدة بيانات Supabase (PostgreSQL)، واستضافة Vercel، والتطبيق PWA.
- **ليش بدون React؟** المشروع لازم يكون خفيف وسريع على جوالات بسيطة، وبدون خطوة بناء، فيكون أسهل تحديثه ونشره.
- **كيف حميت البيانات؟** الجداول مقفلة. ما في شي يتقرأ إلا عن طريق دوال تتأكد من الجلسة والصلاحية. كلمات المرور مشفرة، وبعد ٨ محاولات غلط الحساب ينقفل ربع ساعة. وفي إعدادات حماية للمتصفح في `vercel.json`.
- **كيف تأكدت إنه يشتغل على كل الجوالات؟** عندي فاحص (`tools/qa`) يفتح الموقع على ٢٠ جهاز (سامسونج، آيفون، آيباد، هواوي، ريدمي، كمبيوتر)، ويضغط كل زر في كل شاشة، ويفحص التنسيق.
- **سويته بروحك؟** قل الواقع: الفكرة والقرارات والتصميم والتجربة منك، واستخدمت أدوات برمجة بالذكاء الاصطناعي كمساعد. هذا طبيعي اليوم. والأهم إنك فاهم كل جزء، وهذا الدليل يساعدك.
